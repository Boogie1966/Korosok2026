## Pontosság

A megállók helye nem becslés: a hivatalos folyamkilométerekből lett kiszámolva, a mederen mérve.
Ellenőrzés – a számolt pontok a hivatalos KHESZ GPS-koordinátáktól **139 m** (halászlaki vasúti híd)
és **163 m** (Hortobágy-Berettyó torkolat) távolságra esnek. A mért mederhossz Szanazugtól az
összefolyásig 37,20 km, a hivatalos Kettős-Körös hossz 37,3 fkm.
